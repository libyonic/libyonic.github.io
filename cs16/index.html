CS1.6 僵尸地图安装指南

快速步骤

  1. 下载地图包 获取对应的 .zip 或 .rar 压缩包。
  2. 解压文件 将压缩包解压至 Steam/CS1.6 的 maps 文件夹。
  3. 配置服务器 在 server.cfg 中添加地图名或使用 rcon 指令。
  4. 启动游戏 进入游戏控制台输入 "map 地图名" 开始游玩。

详细操作说明

CS1.6 的地图包安装非常简单。首先，请确保你已经拥有 Steam 版或单机版（HLDS）的 Counter-Strike 1.6 安装目录。找到 cstrike/maps 文件夹。

下载地图包后，请使用 WinRAR 或 7-Zip 打开压缩文件，你会看到类似 de_dust2.bsp 或 zs_arena.bsp 的文件。直接将它们复制到 maps 文件夹中即可。

如果你是搭建局域网服务器，需要在服务器根目录的 cstrike/cfg 文件夹下找到 server.cfg，添加 map <地图文件名.bsp> 指令来指定地图。如果是单人游玩，启动游戏后在控制台输入 map <地图文件名.bsp> 即可进入。

常见问题解答 (FAQ)
下载的地图在游戏中看不到？
请检查文件是否完整解压，以及文件名是否正确（确保 .bsp 后缀存在且没有多余的中文乱码）。如果是单人游玩，请确保你是在控制台输入指令，而不是直接在游戏菜单选择。
CS1.6 僵尸模式需要什么插件支持？
通常需要安装 AMXX (Amx Mod X) 插件平台，以及对应的僵尸插件（如 Zombie Plague 或 Zombie Mod）。地图包说明中通常会附带插件列表。
如何创建一个带僵尸模式的局域网服务器？
使用 HLDS (Half-Life Dedicated Server) 安装 CS1.6 客户端，然后安装 AMXX 插件和僵尸 MOD 插件，最后在控制台输入 sv_lan 1 开启局域网模式并启动地图。
